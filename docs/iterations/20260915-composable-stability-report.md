| 问题 | 已采用的处理 |
| --- | --- |
| 三门可以排进课表，却只给出两门 | 按课程号做有上限的组合搜索，检查新课彼此与原课表的周次、星期和节次冲突 |
| 纯推荐正文被空校园展示覆盖 | 以真实查询结果决定展示，不因误调用显示工具丢掉社区回答 |

| 局部消歧丢失其他课程或已算时间结果 | 同轮按查询保留候选；课程号只影响相关查询，时间改变后统一重算 |
| 展示候选后没有完成课程号选择 | 展示工具可直接选择已查候选，复用现有时间核对 |
| 未确认校区码出现在结果里 | 只保留确认下沙的开课记录，未知部分说明未能核实 |
| 只问某天某时段，却返回整周课表 | 按指定范围展示占用与空闲；E31真实返回周二6–7空闲、8–9占用 |
