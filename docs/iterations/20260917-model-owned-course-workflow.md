# 课程流程：模型理解与回答，代码校验与执行

## 修改

移除 Agent/Provider 的完成回调、强制展示补调用、工具强制选择、校园查询后的流式文本屏蔽，以及最终回答的表格/管理回执覆盖。`show_course_results` 保留兼容名称，但现在只是可选的结构化查询和筛选工具，调用后模型仍可收藏、追问或直接回答。原格式化函数仅作为已有查询测试的检查辅助保留在 `_test.go`，不进入发布程序；收藏和模拟方案的固定回执拼接已删除。

检索关键词只来自模型显式参数，不再截前四字或自动删课程后缀。工具保留真实返回的候选和原始 ID，模型负责判断名称对应；收藏传入候选中的真实班级 ID 即代表模型的选择，不要求额外“展示选定”步骤。没有加入新的相似度规则、意图分类器或业务状态机。

收藏允许同一课程多个教学班，用户要求全部收藏时使用全部符合条件的班；不自动套用排课“一门一个班”的限制，不再规定多班必须询问。Skill 明确完整继承上下文目标、主动处理必要的名称补查、简洁总结最终状态。课程查询单次和累计上限调整为 48，避免原 12 门截断完整推荐清单；每轮 40 次校园 HTTP、最多 3 路开课请求、12 次工具预算、6 轮带工具模型请求、时间和响应大小限制保持。排课组合仍独立限制为 12 个课程号及 100,000 步。

App 持有按对话 ID 与校园授权摘要隔离的 `CourseContexts`。保存精简公开课程记录、原查询名和最后一次收藏操作状态，固定 30 分钟有效期、最多 64 个对话、每项 256 KiB。追问不续期。缓存不含令牌、原始接口响应、个人课表、收藏列表快照或模拟 revision；退出进程即清除，删除对话清除，过期/授权变化后重新核实。结构化时间槽在恢复时重新解析。SQLite 格式不变。

ID 来源、权限、去重、最新原收藏读取与保留、写后复查、未知写入不自动重试、模拟 revision 和冲突计算仍由代码执行。收藏结果增加确定性的课程数、班级数、新增数与当前总数。局部课表的占用、空闲、信息不完整状态也由代码计算为结构化窗口，模型负责组织措辞。

## 两段实际对话回放

`internal/agent/testdata/conversation_replays.json` 保存用户两段实际对话的初始推荐与后续三次收藏指令。初始推荐来自本机已保存对话；不重新抓取社区内容，以免推荐变化掩盖原问题。教学班目录取自原对话可见的官方核实表，班级 ID 替换为测试 ID。

`TestLiveConversationReplays` 使用本机配置的真实模型；固定校园 HTTPS 路由被测试传输层导向隔离目录与收藏接口，不修改实际校园收藏。该验证覆盖模型决策、工具调用、读取/合并/写入/复查及多轮复用，但不代表重新验收生产 Neo 服务或证明目录中缺失课程实际未开。

最终运行结果：

| 对话 | 首次请求的工具链 | 收藏结果（不含原有项） | 两次追问新增检索 |
| --- | --- | --- | --- |
| 作业少、考核轻松 | 核实 → 收藏 | 6 门、16 个教学班 | 0、0 |
| 高分、最好不闭卷 | 核实 → 收藏 | 8 门、22 个教学班 | 0、0 |

断言检查首轮覆盖全部预期班级，检查未找到的正向推荐也被查询，验证近似名称、多班、原收藏保留、无关 AI 课程未被写入，以及追问没有重复搜索或再次索要授权。回放中曾暴露关键词过窄、拆批漏查和重复要求被误解为要求添加未找到课程；通过调整工具参数容量和模型说明修正，没有添加自动匹配或强制收尾逻辑。

可复跑：

```bash
HDU_STATION_LIVE_REPLAYS=1 go test ./internal/agent -run '^TestLiveConversationReplays$' -v -count=1 -timeout=15m
```

最终可见回答、工具名、检索词及隔离收藏结果位于应用数据根目录 `logs/conversation-replays-20260917/replay-1.json` 和 `replay-2.json`。这些报告仅含公开课程和测试 ID。
