# 补空以模拟课表为准

更新 timetable-fit、course-feasibility 及收藏/模拟管理组合说明。补空和冲突筛选使用 `scheduleSource=simulation`，仅明确查询学校真实课表时使用 actual。

工具默认读取同学期 Neo 模拟方案的 effectiveCourses，使用结构化 slots 转换并合并占用周次节次。模拟加入占位、模拟移除释放时间；识别已存在教学班/同课程号，避免重复排入。每次适配读取当前版本，同轮模拟操作会使旧适配结果失效，展示前重新计算。授权缺失、接口失败、未知或无效时间不回退真实课表，也不确认空闲。结果标注模拟来源与版本。

验证：

- `make test`：Go 与前端43项测试通过；`make frontend-check` 通过 test/build 依赖执行。
- 新增模拟加课占位、模拟退课释放、外部修改后重新读取、未知/无效时间、读取失败无回退、模拟修改后展示重算测试，通过。
- 最新工具测试与 `make build` 通过，已更新本项目桌面应用。
- 实际 Station 授权下模拟课表读取与3个候选班的适配通过。
- 新增问题 M05，真实模型调用 fit_courses_to_schedule → show_course_results，输出模拟来源与版本，5.9秒完成，无空答或错误。证据位于应用数据根目录 logs/simulation-fit-qa-20260917/。

本轮未提交收藏或模拟方案的写请求。真实账号当前无模拟动作，因此加课占位、退课释放的差异由隔离 fixture 覆盖，未为验收改动用户方案。
