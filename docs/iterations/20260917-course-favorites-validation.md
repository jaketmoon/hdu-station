# 课程收藏 Skill 与自由组合验收

2026-09-17，基于 main 工作区。用户已重新授权，并要求加入收藏能力及多种组合问题集。此次只开放课程收藏添加，不开放模拟方案或学校真实选课。

## 实现

新增 `course-favorites`，与现有推荐、开课核实、课表适配共用同一 Agent 和本轮官方候选。没有增加固定流程或按用户文本分类的路由器。

`add_course_favorites` 仅接受本轮已经核实并选定的教学班，跨轮需要重新核实身份。用户要求无冲突收藏时，必须从最新无冲突组合取班级。多个班尚未选定时展示选项，明确提示尚未收藏。收藏回执由宿主输出，模型不能把拒绝写入改写为成功。

上游 `/academic/class/fav` 的 POST 是全量覆盖，因此宿主固定执行读取、合并去重、写入、读回核对。进程内所有会话串行处理，排队可取消；无法读取原列表时不写，响应丢失后只复查，不自动重复 POST。未知结果在本轮禁止继续尝试写入。上游没有 revision/CAS，仍不能保证与其他客户端同时覆盖时的原子性。
