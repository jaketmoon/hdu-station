# 规则收敛与单轮复测

本次按用户要求，删除针对问句的时间补丁，让程序专注于结构化参数和官方数据。保留课程发现、开课核实、课表查询与组合适配的独立使用能力。

## 实际修改

- 删除 `course_time_guard.go`：不再用正则理解“只要周几”“全天空着”、否定和钟点表达。
- 删除 Agent 向校园工具传递用户原文的状态链，以及据此清空时间参数、覆盖计算结果和展示的逻辑。
- 保留星期/节次范围、时段并集与交集校验，周次冲突、课表完整性、课程号区分、下沙筛选、组合排课、候选与偏好状态处理。
- `timetable-fit` 只将时间说明收敛为通用约定：歧义或矛盾先澄清，没有官方钟点对照时不猜节次。其余三个 Skill 未改。

相对收敛前版本净删106行业务代码、199行对应问句测试；正常工具行为的测试保留，没有改题目或预期。子代理只读核对未发现结构化校验、候选或状态功能被误删。
