# HDU Station：选课情报终端

## 设计与调研

保留历史、对话、输入、设置四个核心区域，以通讯终端组织界面。深紫黑底配粉色主操作、青色情报表格。首页只保留原创像素夜景、逐字标题「情报台在线，等待你的指令。」和三个快捷入口；移除 ZERO 字标、夜景招牌、开场联络员卡片及重复的中英文装饰说明。输入框保留 `[ COMMAND ] >`、实际发送操作和必要的信息说明，移除发送／换行提示。

前四个项目作为交互和视觉参考，未复制其源码或引入运行依赖。Share Tech Mono 用于英文 HUD，标题使用方舟像素，长篇中文正文仍使用清晰的系统字体。字体自托管、离线打包，字体 SIL OFL 许可随桌面应用分发。夜景为原创，没有游戏原素材或远程图片。

中文字体来自 `ark-pixel-font-12px-proportional-otf.woff2-v2026.09.01.zip` 中的 `ark-pixel-12px-proportional-zh_cn.otf.woff2`，使用 FontTools 裁剪字符「情报台在线，等待你的指令。」、保留名称与许可元数据，输出 `frontend/src/assets/station-greeting.woff2`（1660 字节）。构建时预载独立字体文件，避免小字体内联为 Data URL 后在原生 WebView 回退；已在重新打包的原生窗口验证像素字形。开发和桌面包都不依赖在线字体服务。

## 实现边界

- React 仍只通过 `api.ts` 调用 Wails，不新增 HTTP 后端或产品演示回复。
- 对话加载先保留当前记录，新记录就绪后再整体切换。导航序号丢弃慢请求的过期结果；加载失败保留当前对话；新建通讯取消尚未完成的切换。后台回答完成不会取消正在加载的目标对话。
- 记录就绪后一次性更新界面，不再使用录像带转场或动画等待。读取期间保留草稿并暂缓发送，避免指令落到上一条对话。
- `Dialogue.tsx` 将 SSE 文本与呈现游标分离，以 `Intl.Segmenter` 字素边界保护 emoji 和组合字符。历史直接显示，替换汇总重置游标，停止或失败立即保留已接收内容。
- Markdown 先解析，再按源位置裁剪语法树，不直接截断 Markdown 标记。表格与代码块整体显示；引用仍由宿主校验及打开，复制获取完整已接收原文。
- 「立即显示」跳过本条回答的呈现动画，后续分片直接显示，不取消请求。「中止通讯」仍使用原有按请求 ID 隔离的取消接口。
- 显示偏好写入原有 `config.yaml` 的 `appearance.instant_text`。`SaveAppearance` 持有配置锁，只更新逐字显示偏好，可以在问答期间使用；保存失败保留原状态，不创建浏览器本地存储。
- 系统 `prefers-reduced-motion` 覆盖逐字显示偏好。旧配置中的 `reduce_effects` 被忽略，下次保存时移除。
- 窄窗口侧栏锁定主区域并管理焦点，Escape 关闭并恢复菜单焦点。Command/Ctrl+K 新建通讯，Command/Ctrl+, 打开设置；保留 IME、Shift+Enter。删除通讯先在列表内确认。
- Agent 只增加轻量通讯语气说明，不改变工具、事实规则、课程筛选或授权范围。

## 验证

检查通过：39 项前端单测、26 项双窗口 E2E、全部 Go 单测，以及前端检查和 macOS 打包。此前配置与桌面用例 race 检查已通过。本轮增加慢加载、快速切换、过期结果、加载失败、草稿保留、后台回答结束与切换并发，以及像素标题和文案精简的回归覆盖。独立的原生预览应用用于核对离线字体、像素资源和真实历史表格。
