# 选课稳定性迭代

## 范围与验收

保留原始 60 题和旧结果；新验收区分「支持的查询」与「边界说明」，不把拒答计作完成选课。支持教务默认当前学期、下沙校区、明确课程名称/课程号、明确星期与节次；社区体验只使用当前已连接来源。下学期、历史学期、其他校区、实时余量、考试安排、资格及学分认定、代选退课不在范围内。无法唯一解释的简称、钟点或矛盾偏好要求补充，不能猜测。

## 问题归类与处理

| 问题类 | 处理方式 | 代表题 |
| --- | --- | --- |
| 超出能力范围 | 固定说明仅默认本学期下沙；未来/指定学期、其他校区、资格余量考试、代选退课不查询；纯课表与钟点澄清 | E31–E44、E55 |
| 来源未连接、限流拖住其他来源 | 查询前实际状态检测，失败跳过；QQ限流立即返回并进入冷却 | E45–E47、E02/E03 |
| 名称模糊或模型改写 | 完整名后核心词，保守词干匹配；剥离复制的末尾课程号；其余列官方候选要求补全 | R03/R05、E12–E17、E35/E36、E50 |
| 时间理解与追问丢限制 | 程序提取有限星期/节次语法，跨轮更新；既有忙时不当允许时间，矛盾澄清 | R02–R05、E19–E29、E50–E55 |
| 只读课表就结束、漏组合 | 唯一核实工具形成闭环；按课程号有界搜索最多门数互不冲突组合，数量不足明示 | R01、E27、E30 |
| 口碑套错教师、无依据保证轻松 | 区分询问与体验；统一说明未逐课程逐教师核实到本学期，不能补造结论；严格教学要求暂不筛选 | E01–E10、E30、E49 |
| 工具名/参数错误及展示 | Eino错误恢复；Go生成官方表格，隐藏班级号，保留课程号 | 原11个失败题及全题集 |

范围内信息不足仍可能无法给出满意推荐；这类结果单列为资料不足，不与成功选课建议混算。原始60题及原预期完整保留。

## 迭代计划

1. **范围及展示**：固定当前学期和下沙，隐藏班级号；复测学期、校区及显示题。
2. **核实闭环**：把官方查询、保守名称匹配、课表核实、最终展示合成一次工具调用；杜绝只读课表即结束、漏掉候选和重复选择丢课。复测名称、推荐后追问及完成条件。
3. **时间及组合**：程序解析有限时间语法；按课程号搜索无冲突组合，限制推荐门数。复测时间限制、周次、组合与多轮修改。
4. **失败恢复与收敛**：恢复未知工具及参数类型错误，压缩 Skill；每阶段运行受影响题，最终运行完整 60 题并复测失败题及原 5 个桌面例子。

每阶段保留独立真实运行记录、人工判定和未解决事项；单元测试验证确定性逻辑，真实模型测试验证整个流程，二者分开统计。私人的完整问答保存在应用数据根目录 logs 下。

## 调查依据

- Eino 已提供未知工具处理与调用中间件，无需新增框架：[v0.9.13 官方源码](https://github.com/cloudwego/eino/blob/v0.9.13/compose/tool_node.go)、[官方 middleware 文档](https://www.cloudwego.io/docs/eino/core_modules/components/tools_node_guide/#middleware-mechanism)。由排查子代理验证。
- 旧组合采用首个可用班，可能挡住后续课程。使用有界分支限界枚举，每门课至多一个班，无新增依赖；参考 [Google OR-Tools](https://developers.google.com/optimization/pack/knapsack)。由算法子代理实现并验证反例。
- QQ限流冷却避免在共享锁中长等待，参照 Go [Mutex](https://pkg.go.dev/sync#Mutex.Lock) 与 [context](https://pkg.go.dev/context#WithTimeout) 的互斥/取消语义；由排查子代理实现并补限流、恢复、取消及其他来源不受阻测试。
- 明确课程的官方查询复用已有named tool choice；[DeepSeek官方协议](https://api-docs.deepseek.com/api/create-chat-completion)要求关闭thinking才支持required/named，现有provider已经关闭。由子代理核验，当前配置通过连续3次真实调用验证，不加网关fallback。
